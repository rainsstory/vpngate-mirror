vpngate-mirror

Static mirror of the public VPN Gate aggregate API.

Endpoint:

/api/iphone/

Client base URL:

https://rainsstory.github.io/vpngate-mirror

Payload shape — *vpn_servers, then a #HostName,IP,Score,… header, then CSV rows:

*vpn_servers
#HostName,IP,Score,Ping,Speed,CountryLong,CountryShort,NumVpnSessions,…

Refreshed by a scheduled workflow in this repository. The file is served as text/html because GitHub Pages picks the content type from the filename; parse the body as text, not by MIME type.

Upstream: www.vpngate.net/api/iphone/ (public data, VPN Gate project, University of Tsukuba).
